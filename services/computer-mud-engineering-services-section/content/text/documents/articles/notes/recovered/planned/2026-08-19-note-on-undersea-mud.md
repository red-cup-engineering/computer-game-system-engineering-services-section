# Undersea MUD (the SHRIMP ecology)

A giant cooperative MUD, close kin to The Commons vision: an undersea wuxia setting with an ecological world where grass grows, gets picked, composts, and so on — referenced against Albion Online's player-driven economy and EVE Online's daily regeneration mechanics as the nearest real precedents.

The load-bearing math for this game lives in a separately authored document, the SHRIMP ecology brief: Lorentzian causal-set light cones, a four-way settling-regime taxonomy (finite, scott, transfinite, aperiodic), and a K4 gauge-holonomy mechanism proposed as a candidate for cast-member temperament. That brief hasn't been read as part of this notes directory's own corpus, so its math claims should be treated as unverified here — anyone picking this concept up should read it directly before treating the claims as settled.
